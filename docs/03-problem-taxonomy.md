# 03 · 世界模型的关键问题与代表方法

[上一篇：WAM](02-world-action-models.md) · [返回总览](../README_cn.md) · [论文索引](paper-index.md)

世界模型用于决策时，需要保留历史状态、正确预测动作后果，并提供足以支持控制的信息。这些要求分别涉及记忆、动态预测和状态表征。

## 1. 问题定义

用于决策的世界模型，需要在观察、动作与历史条件下产生有用的未来预测。预测质量应分开检验：

| 问题 | 常见错误 | 目标 |
|---|---|---|
| 长期状态一致性 | 返回旧场景时布局变化、遮挡后认错对象、多阶段任务状态丢失 | 保存并正确更新与当前决策相关的状态 |
| 动作与物理正确性 | 预测忽略动作、物体穿透、交互关系突变、动作超出控制范围 | 正确预测动作引起的状态变化，满足机器人的运动约束 |
| 面向动作决策的表征 | 视频合理，但动作模型关注背景或丢失关键几何信息 | 保留足以支持动作选择的信息 |

面向动作决策的表征需要保留足够的信息（Action-Sufficient）：即使压缩了外观细节，仍能区分不同动作的后果。三个问题相互关联，对象状态同时影响记忆与控制，语义 latent 同时影响效率与泛化。

<a id="memory"></a>
## 2. 长期状态一致性

### 2.1 Spatial Memory：可检索的空间与情景记忆

**动机**：有限上下文使视频世界模型在回访时遗忘旧区域。

**方法**：在线保存几何结构与历史参考帧，将渲染得到的空间信息、历史画面和近期观察输入生成模型，为再次预测旧场景提供参考。

![Spatial Memory 的空间记忆与视频生成结构](../assets/figures/spatial-memory.png)

*论文图：[Video World Models with Long-term Spatial Memory](https://arxiv.org/abs/2506.05284)。空间记忆、历史参考帧和近期上下文共同支撑未来生成。*

**实验结果**：作者在场景回访与一致性评测中报告生成质量及长期一致性的改善。

**讨论**：几何记忆便于空间检索，但依赖位姿与重建。动态对象属性、任务进展和接触状态的更新仍需要超出静态地图的记忆机制。

### 2.2 RELIC：压缩历史与流式生成

**动机**：长历史增加计算与缓存负担，交互世界又需要低延迟和动作可控性。

**方法**：把历史压缩为 latent token，将相对动作与绝对相机位姿写入 KV 记忆；通过长时训练与蒸馏将双向教师转为因果流式学生。[RELIC](https://arxiv.org/abs/2512.04040)

**实验结果**：14B 模型在 **4 张 H100** 上达到 16 FPS 的视频生成吞吐。[v1 正文](https://arxiv.org/html/2512.04040v1)

**讨论**：历史压缩降低缓存开销，但少见关键事件的保留和任务相关历史的检索构成压缩记忆的主要挑战。

### 2.3 WorldDP：对象中心状态与分层规划

**动机**：图像整体特征不易分开追踪对象，多阶段任务需要依次完成对象状态变化。

**方法**：以对象中心状态学习动态，在高层搜索可行子目标，再由低层 Diffusion Policy 执行。论文还使用对象级代价比较规划状态。[WorldDP](https://arxiv.org/abs/2606.08775)

**实验结果**：在 Cube-Triple 任务中，以完成全部三个方块的操作为成功标准，WorldDP 的成功率为 30%，HECRL* 为 12%。[v1 Table 1](https://arxiv.org/html/2606.08775v1)

**讨论**：对象中心状态支持多阶段子目标规划；长期身份保持、遮挡恢复与选择性记忆则要求对象表示在更长交互过程中持续更新。

## 3. 动作与物理正确性

动作与物理约束主要通过三种方式影响模型：在输入中明确表示动作，用轨迹和实体关系监督训练，以及通过后训练优化生成结果。它们分别改善动作响应、运动一致性和可执行性。

### 3.1 动作条件建模：Ctrl-World

**动机**：动作条件过于粗糙时，模型可能生成连贯画面，却无法忠实执行指定控制。

**方法**：逐帧动作条件、多视角预测及位姿条件历史检索，构成可与通用机器人策略交互的模拟器。论文使用 DROID 的 95k 轨迹，涉及 564 个场景。[Ctrl-World](https://arxiv.org/abs/2510.10125)

**实验结果**：模型支持超过 20 秒的轨迹生成与策略排序。使用筛选出的想象轨迹微调 π₀.₅ 后，未见对象与新指令任务的成功率从 38.7% 提升到 83.4%，增加 **44.7 个百分点**。[v3 §5.4](https://arxiv.org/html/2510.10125v3)

**讨论**：细粒度动作对齐改善条件接口，接触力、摩擦以及分布外动作下的可靠预测仍依赖数据覆盖与动态建模能力。

### 3.2 结构监督：PhysisForcing

**动机**：运动区域变形和接触时实体关系错误，会降低视频作为模拟器的可靠性。

**方法**：点轨迹监督约束局部 DiT 特征，冻结视频理解编码器提供实体间关系目标，联合像素级轨迹和语义级关系对齐。

![PhysisForcing 的轨迹与关系监督](../assets/figures/physisforcing.png)

*论文图：[PhysisForcing](https://arxiv.org/abs/2606.28128)。轨迹匹配与实体关系对齐分别约束局部运动和交互结构。*

**实验结果**：在 WorldArena action-planner 协议下，闭环成功率由 16% 提升到 24%，增加 8 个百分点。

**讨论**：轨迹与关系监督将训练重点移向物理相关区域，其约束能力受伪标签精度和覆盖范围限制。

### 3.3 语义状态、记忆与效率：DexWorldModel

**动机**：像素重建、随历史增长的存储以及视频动作串行计算，都可能限制部署。

**方法**：以 DINOv3 patch 特征作为预测目标，使用双状态 TTT Memory，并通过推测式异步推理，在执行动作的同时完成部分去噪计算。[DexWorldModel](https://arxiv.org/abs/2604.16484)

**实验结果**：作者报告异步推理使阻塞延迟下降约 50%，长期记忆机制的存储规模相对于历史长度保持 $O(1)$。

**讨论**：语义状态、长期记忆与异步推理共同减少外观重建和串行计算开销。精细几何与接触信息在语义压缩中的保留程度，是其用于精密操作时的关键问题。

### 3.4 后训练对齐：EVA

**动机**：视觉上连贯的机器人视频经动作解码后，仍可能产生不稳定或违反本体限制的控制。

**方法**：在真实轨迹上训练并冻结 IDM，将生成视频转为动作，再根据速度、加速度、jerk 和本体限制构造奖励，通过强化学习后训练视频模型。[EVA v1](https://arxiv.org/html/2603.17808v1)

**实验结果**：在 v1 的真机实验中，相比未使用 RL 的 EVA，加入 RL 后 Seen 平均成功率由 52% 提升到 64%，OOD 由 42% 提升到 60%。

**讨论**：动作约束通过奖励反馈给视觉生成，但奖励同时继承 IDM 的误差。动作平滑性、本体可行性与任务完成度分别对应不同的优化目标。

### 3.5 后训练对齐：ABot-PhysWorld

**动机**：通用视频数据与似然训练可能容忍穿透、反重力等生成错误。

**方法**：构建物理标注的操作片段，以解耦判别器分别评估物理合理性与动作一致性，通过 DPO 后训练 14B 视频模型。[ABot-PhysWorld](https://arxiv.org/abs/2603.23376)

**实验结果**：作者在 PBench 和 EZSbench 的物理合理性与轨迹一致性评测中，与 Veo 3.1、Sora v2 Pro 等模型进行了比较，报告了相应指标的改善。

**讨论**：偏好优化依赖判别器覆盖和标注分布，学习到的物理偏好与显式物理约束具有不同的泛化边界。

<a id="action-sufficient"></a>
## 4. 面向动作决策的表征

### 4.1 LaWAM：紧凑 latent 视觉子目标

**动机**：逐像素视频预测包含外观冗余，且会增加部署计算。

**方法**：在视觉基础模型的 latent 空间学习潜在动作模型，复用前向解码器预测未来特征，再让动作模块读取当前特征与预测子目标。[LaWAM](https://arxiv.org/abs/2606.15768)

**实验结果**：作者报告 LIBERO 98.6%、RoboTwin 91.22%，以及每个动作块预测 187 ms。延迟实验使用 A100、BF16 和 10 步动作去噪，计时范围为模型计算，不含模拟器与机器人执行开销。[v2 Appendix F.1](https://arxiv.org/html/2606.15768v2)

**讨论**：latent 子目标提供紧凑的预测接口，几何细节损失、预测误差和解码器泛化共同影响下游控制表现。

### 4.2 AGRA：对齐世界模型与动作模型的表征

**动机**：即使预测视频合理，动作头仍可能关注无关背景。生成逼真视频所需的特征，并不一定能直接支持动作解码。

**方法**：论文用动作头注意力与干预诊断问题，通过基础视觉编码器提供空间语义教师，对齐视频扩散中间特征，改善动作相关区域的表示。

![AGRA 对齐世界模型与动作解码器的表征接口](../assets/figures/agra.png)

*论文图：[Making Foresight Actionable](https://arxiv.org/abs/2606.12217)。视觉教师引导世界模型中间特征的空间语义对齐。*

**实验结果**：在 RoboCasa GR1 的 10% 训练数据设置下，Unseen Combinations 成功率从 WAM 的 59.57% 提升到 AGRA-ActionCondPass 的 66.28%，增加 6.71 个百分点。[v1 Appendix B, Table 2](https://arxiv.org/html/2606.12217v1)

**讨论**：表征对齐改善世界特征的组织和动作相关区域定位；滑移、摩擦等动态仍依赖世界模型本身的预测能力。

## 6. 开放问题

### 6.1 分层状态

对象身份、属性、关系与空间结构变化较慢，接触和运动状态则要求快速更新。如何在统一模型中协调两个时间尺度，使长期记忆支持短时控制，是分层状态建模的核心问题。单一 latent 与分层表示在相同预算下的回访一致性和操作成功率，可以揭示这种分工的作用。

### 6.2 选择性记忆

记忆机制需要决定写入什么、检索什么以及何时更新。新对象、关键接触和拓扑变化提供事件线索，位置、对象、任务与候选动作提供检索条件。有限内存下，选择性记忆能否同时改善遮挡恢复与错误状态修正，仍有待研究。

### 6.3 物理一致性评测

几何连续性、交互关系和动作可执行性对应不同的物理约束。轨迹质量、关系一致性，以及动作违反约束的频率，能否反映真实任务的成功率？建立这些指标与实际执行效果之间的关系，有助于选择训练目标。

### 6.4 预测信息与任务需求

RGB、几何、flow 与交互区域在不同任务中的信息需求并不相同。它们的互补性如何随抓取、移动、放置和精细插入而变化？任务条件的动态选择能否在固定计算预算下优于静态组合？

| 研究问题 | 对比方法 | 实验条件 |
|---|---|---|
| 预测目标 | RGB、几何、flow、交互区域；单目标与组合 | 同一数据、主干、训练步数和参数预算 |
| 任务 | 抓取、移动、放置、精细插入 | 成功定义、环境划分、重复次数 |
| 预训练 | 空间预训练与从零训练 | 数据量、算力与标签成本 |
| 架构 | 多专家与共享模型 | 模型容量、各模块可用的信息与推理成本 |
| 评价 | 成功率、泛化、稳定性、延迟 | 置信区间、硬件、动作块与执行频率 |
