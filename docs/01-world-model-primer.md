# 01 · 世界模型科普

[返回总览](../README_cn.md) · [下一篇：WAM](02-world-action-models.md) · [论文索引](paper-index.md)

世界模型将观察转成内部表示，并预测状态在动作或其他条件下的变化。状态表示决定模型保留哪些信息，动态预测则描述这些信息如何随交互演化。

## 1. 以推杯子理解世界模型

机器人要把杯子推到桌面另一侧。当前图像给出外观，却未必直接给出杯子速度、接触状态、摩擦或被遮挡部分。模型首先从观察和历史形成内部状态，再预测候选动作的后果。状态可以是向量、对象集合、三维结构或其组合。

$$
z_t=E(o_{\le t},a_{<t}),\qquad
\hat z_{t+1}\sim p_\theta(z_{t+1}\mid z_t,a_t),\qquad
\hat o_{t+1}\sim p_\theta(o_{t+1}\mid\hat z_{t+1}).
$$

第一步是表示，第二步是动态预测，第三步是可选的观察解码。预测目标还可以包含奖励、任务进度或终止状态；策略既可以利用解码后的观察，也可以直接在 latent 空间学习行为。[World Models](https://arxiv.org/abs/1803.10122)、[Dreamer](https://arxiv.org/abs/1912.01603)

给定“把杯子推过去”生成一个可能完成任务的视频，描述的是目标条件未来；给定确定的机器人动作预测杯子是否会滑落，描述的是动作条件未来。后者直接支持比较这些具体动作的后果。

## 2. 两条主线

| 方向 | 核心问题 | 状态表示 | 常见问题 |
|---|---|---|---|
| 理解世界 | 什么存在、在哪里、相互是什么关系、历史发生了什么？ | 语义特征、对象状态、空间地图、历史记忆 | 状态遗漏、对象混淆、遮挡后遗忘 |
| 想象未来 | 给定动作或目标后，哪些状态会怎样变化？ | 视频、未来 latent、几何、flow、奖励或价值 | 动作不生效、预测漂移、几何错误、结果失真 |

两者可以共享训练目标与网络。好的表示应保留任务所需的信息；预测未来可以帮助学习动态，但也可能把计算花在与动作无关的纹理上。因此，评价预测时需要进一步追问它向决策提供了哪些信息。

## 3. 发展脉络

潜空间动态、想象学习、预测性表征与交互视频模拟构成了世界模型发展的几条技术路线。

| 年份 | 代表工作 | 核心贡献 |
|---|---|---|
| 2018 | [World Models](https://arxiv.org/abs/1803.10122) | 视觉压缩、时序动态与控制；想象中的学习 |
| 2019 | [Dreamer](https://arxiv.org/abs/1912.01603) | 从 latent 想象轨迹学习策略与价值 |
| 2023 | [DreamerV3](https://arxiv.org/abs/2301.04104) | 跨任务稳定的世界模型与行为学习 |
| 2023 | [I-JEPA](https://arxiv.org/abs/2301.08243) | 预测图像区域表征；本身不是机器人动作条件动态模型 |
| 2024 | [Sora](https://openai.com/index/video-generation-models-as-world-simulators/) | 视频生成作为世界模拟的研究方向 |
| 2024 | [GameNGen](https://arxiv.org/abs/2408.14837) | 动作条件视频预测构成可交互游戏模拟 |
| 2025 | [V-JEPA 2](https://arxiv.org/abs/2506.09985)、[Genie 3](https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/) | latent 预测规划与交互世界生成 |

I-JEPA 以图像区域特征为预测目标；视频与机器人动态建模进一步引入时间和动作条件。[V-JEPA 2](https://arxiv.org/abs/2506.09985)将表征预测用于规划，[Sora 2](https://openai.com/index/sora-2/)则继续探索视频模拟能力。

## 4. 世界模型在决策中怎样使用

### 4.1 在想象中训练策略

模型式强化学习通常交替进行真实数据采集、世界模型学习、想象轨迹生成和策略优化。Dreamer 使用 latent 世界模型展开未来，通过价值估计和策略目标学习行为，随后回到环境中收集经验。[Dreamer](https://arxiv.org/abs/1912.01603)

```mermaid
flowchart LR
    D[真实交互数据] --> W[学习世界动态]
    W --> I[潜空间想象轨迹]
    I --> L[更新策略与价值]
    L --> A[环境中执行]
    A --> D
```

世界模型的偏差会随想象轨迹传播，较长 rollout 可能将策略带离真实数据覆盖的状态。策略还可能利用模型误差，在预测环境中获得高回报，却无法在真实环境中复现该行为。

### 4.2 预测并比较不同动作的结果

给定当前状态，规划器提出多个动作序列；世界模型预测后果，价值函数或任务代价评价候选，执行其中一小段，再获取真实观察。“预测模型”和“选动作的规划器”在这里承担不同职责。

在网页环境，[WebDreamer](https://arxiv.org/abs/2411.06559)探索用语言模型模拟候选网页操作的后果。这个例子展示了预测与规划的跨领域用途，其网页状态和操作空间与机器人动力学不同。

### 4.3 将预测信息交给动作模型

世界模型可以输出目标图像、运动轨迹或 latent 特征，由控制策略据此输出动作。[World Action Models](02-world-action-models.md)进一步将世界预测与动作生成连接到统一学习过程。

## 5. 四类应用

| 应用 | 状态与动作 | 用途 | 主要挑战 |
|---|---|---|---|
| 游戏智能 | 游戏画面、角色控制输入 | 学习交互转移，构建神经模拟环境 | 特定游戏中可玩不等于任意环境泛化 |
| 具身智能 | 机器人观察、本体状态、数值动作 | 视觉计划、动作生成、策略评估、合成经验 | 需验证本体约束、接触与真实执行 |
| 城市智能 | 道路、车辆、交通参与者与运动指令 | 场景预测、驾驶仿真、策略比较 | 驾驶、物流和宏观城市分析使用不同状态和指标 |
| 社会智能 | 个体记忆、计划、行为与群体互动 | 模拟交互过程，分析可能的行为模式 | 行为可信度与对真实社会的预测效度需区分 |

[GameNGen](https://arxiv.org/abs/2408.14837)学习 DOOM 游戏在不同操作下的画面变化；[Generative Agents](https://arxiv.org/abs/2304.03442)以带记忆与反思的智能体构建小镇模拟。[WorldSimBench](https://arxiv.org/abs/2410.18072)则评测了驾驶和机器人等场景中的视频模拟能力。

## 6. 主要能力与评测

| 能力 | 核心问题 | 代表工作 |
|---|---|---|
| 长期一致性 | 离开区域后再返回，原来的状态还在吗？ | [Spatial Memory](https://arxiv.org/abs/2506.05284)、[RELIC](https://arxiv.org/abs/2512.04040) |
| 动作可控性 | 只改变动作，预测是否发生相应变化？ | [Ctrl-World](https://arxiv.org/abs/2510.10125) |
| 物理合理性 | 几何、运动、接触和约束分别在哪些测试中成立？ | [Physics-IQ](https://arxiv.org/abs/2501.09038)、[PhysisForcing](https://arxiv.org/abs/2606.28128) |
| 控制效果 | 预测是否改善动作选择或任务成功率？ | [WorldSimBench](https://arxiv.org/abs/2410.18072)、[AGRA](https://arxiv.org/abs/2606.12217) |
| 泛化与迁移 | 更换对象、场景、任务或机器人后，效果能否保持？ | 各论文的分布外测试与真机实验 |
| 部署效率 | 吞吐、决策延迟、控制频率与显存分别是多少？ | [Fast-WAM](https://arxiv.org/abs/2603.16666)、[DexWorldModel](https://arxiv.org/abs/2604.16484) |

## 7. 术语速查

| 术语 | 含义 |
|---|---|
| Observation / State | 观察是传感器输入；状态是用于预测和决策的内部表示 |
| Latent | 学习到的内部特征，不必可以还原成 RGB |
| Dynamics / Transition | 当前状态和动作到未来状态的预测关系 |
| Rollout | 将预测状态继续作为输入，展开多个时间步 |
| IDM | 逆动力学模型，由相邻或多个状态推断动作 |
| MPC | 反复规划、执行前缀、根据新观察重新规划 |
| VLA | 以视觉、语言等信息生成动作的策略模型 |
| WAM | 将预测性世界建模与动作生成结合的模型或系统 |
| Action-Sufficient | 针对给定任务，表征保留了足以支持动作选择的信息 |
